\# 🛡️ SHEGUARD AI



> A personal safety application designed to help users respond quickly during emergency situations.



SHEGUARD AI brings essential safety tools into one mobile application, including SOS emergency assistance, trusted contacts, location sharing, emergency calling, SMS assistance, safe places and Safe Exit.



\## 🚨 Features



\- 🆘 SOS Emergency

\- 👥 Trusted Contacts

\- 📍 Location Sharing

\- 📞 Emergency Calling

\- 💬 SMS Emergency Alerts

\- 🏥 Nearby Safe Places

\- 🚪 Safe Exit

\- 🗺️ Google Maps Integration
